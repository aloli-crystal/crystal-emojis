== v0.2.1 — 2026-04-29

=== Changed

* **GitHub repository renamed** from `aloli-crystal/crystal-emojis` to
  `aloli-crystal/emojis` (Aloli naming convention: original creations
  drop the `crystal-` prefix). Old links redirect automatically.
* `name:` field in `shard.yml` updated from `crystal-emojis` to `emojis`.
* Build target / CLI binary renamed `crystal-emojis` → `emojis`
  (`shards build emojis` → `bin/emojis`).
* New entry-point shim `src/emojis.cr` (loads `src/crystal_emojis.cr`);
  `require "crystal-emojis"` → `require "emojis"`.

== v0.2.0 — 2026-04-26

**Repo renamed and shard merged.** What used to be
`emojis-lite` is now `emojis` ; what used to be
`emojis-full` is being deleted, its functionality folded
into this single shard via the new on-disk cache.

=== Added

* **`CrystalEmojis::Cache` module** — on-disk extension of the
  embedded curated set. Lookup chain : embedded set first, then
  cache. Enables full Twemoji coverage (~4000 SVG) without
  inflating dependent binaries.
* **`Cache.pull(source:, system:)` API** — programmatic download
  trigger. Apps can populate the cache from inside their own
  Crystal code (no CLI dependency), and configure source URL
  (private mirrors) and target (`user` vs `system`-wide cache).
* **`Cache.dir`, `Cache.size`, `Cache.populated?`** — inspection.
* **`bin/emojis` CLI** with sub-commands `pull`, `info`,
  `purge` and short/long flags `-s/--source`, `--system`,
  `-v/--version`, `-h/--help`.
* **Custom mirror support** — `pull --source URL` lets you point
  at a private NAS / Nexus / S3 bucket. Mirrors should ship a
  `MANIFEST.txt` listing the codepoint keys ; the upstream Twemoji
  repo is auto-discovered via the GitHub tree API.
* **XDG-conventional cache path** with macOS variant + `--system`
  override + `CRYSTAL_EMOJIS_CACHE_DIR` env var.

=== Changed

* `emojis-lite` → `emojis` (GitHub repo renamed).
* `CrystalEmojis.svg` now falls back into the cache after the
  embedded set — same signature, broader coverage.

=== Deprecated / removed

* `emojis-full` shard is being deleted. Use this shard
  with `emojis pull` instead.

=== Migration from v0.1

In your `shard.yml` :

[source,yaml]
----
# Before
emojis-lite:
  github: aloli-crystal/emojis-lite

# After
emojis:
  github: aloli-crystal/emojis
  version: "~> 0.2"
----

The Crystal API is unchanged (module name `CrystalEmojis`).
