== v0.1.0 — 2026-04-26

First public release. Curated set of ~200 emoji rendered as SVG,
embedded at compile time. Sourced from
https://github.com/jdecked/twemoji[Twemoji] (MIT).

* **208 emoji** covering status & validation, colour circles &
  squares, geometric shapes, faces (classic + emotion), hands &
  gestures, dev tools, security, communication, places, nature,
  media, music, documents, writing, money, notifications & time,
  arrows, miscellaneous symbols.
* **API** : `CrystalEmojis.svg(char)`, `.svg(codepoint)`,
  `.includes?(char)`, `.size`, `.keys`, `.each { |key, svg| … }`.
* **Compile-time embedding** via the `read_file` macro — no
  runtime `data/` directory needed.
* Covers the « 90 % case » of emojis you'd actually use in a
  technical document. For the full ~3700-emoji set (including
  ZWJ joins, skin tones, regional flags), use `crystal-emojis-full`.
* MIT for the Crystal code ; embedded SVGs are Twemoji CC-BY 4.0
  (attribution to Twitter/Twemoji required when redistributing).
* Bilingual README (EN + FR), CI, ameba lint.
* **14 unit tests, all green.**
