= emojis
:toc: macro
:toclevels: 2

Rendu d'emojis pour Crystal — set curé de ~200 SVG embarqués depuis
https://github.com/jdecked/twemoji[Twemoji], plus un cache disque
optionnel pour le reste du catalogue (~4000 SVG, ~18 Mo). Crystal
pur, sans dépendance d'exécution pour le set curé.

🇬🇧 Read this in English: link:README.adoc[README.adoc]

toc::[]

== Migration depuis emojis-lite v0.1

Le shard a été renommé de `emojis-lite` à `emojis`
en v0.2. Pour migrer :

[source,yaml]
----
# Avant (v0.1)
dependencies:
  emojis-lite:
    github: aloli-crystal/emojis-lite

# Après (v0.2)
dependencies:
  emojis:
    github: aloli-crystal/emojis
    version: "~> 0.2"
----

L'API Crystal est inchangée (nom de module `CrystalEmojis`).
`emojis-full` a été fusionné dans ce seul shard (via le
mécanisme de cache) et va être supprimé.

== Comment ça marche

Lookup en deux couches :

. **Set curé embarqué** : ~208 emojis cuits dans votre binaire à
  la compilation (~840 Ko). Couvre le 90 % des cas de
  documentation technique : status, couleurs, outils dev,
  visages courants.
. **Cache disque** : le reste du catalogue Twemoji, téléchargé à
  la demande et stocké sous `$XDG_CACHE_HOME/emojis/svg/`.
  Vide par défaut — vous (ou votre outil aval) le populez.

Comme ça chaque consommateur ne paie que pour ce dont il a
besoin : le set curé est toujours là, la longue traîne (~3800 SVG
supplémentaires) ne s'embarque que sur demande explicite.

== API (utilisable depuis votre application Crystal)

[source,crystal]
----
require "emojis"

# === Lookup ===
# Cherche d'abord dans le set embarqué, puis dans le cache disque.
CrystalEmojis.svg('✅')   # => "<svg ...>"
CrystalEmojis.svg(0x2705) # => idem
CrystalEmojis.svg('🦄')   # => nil si cache vide, "<svg ...>" une fois mis en cache

# Séquences multi-codepoint (jointures ZWJ, tons de peau, drapeaux)
# typiquement disponibles uniquement depuis le cache.
CrystalEmojis.svg([0x1F468, 0x200D, 0x1F4BB])  # 👨‍💻

# === Gestion du cache (programmatique) ===
# Déclencher le téléchargement depuis votre application — pas
# besoin de la CLI.
CrystalEmojis::Cache.pull
# => télécharge ~4000 SVG dans le cache utilisateur, retourne le compte

# Surcharger la source — pointer vers votre miroir privé.
CrystalEmojis::Cache.pull(source: "https://nas.aloli.local/twemoji/svg")

# Écrire dans le cache système (nécessite root, utile pour les
# serveurs FreeBSD provisionnés via beryl, etc.).
CrystalEmojis::Cache.pull(system: true)

# Inspection
CrystalEmojis::Cache.dir         # => "/Users/.../Library/Caches/emojis/svg"
CrystalEmojis::Cache.size        # => 0 initialement, ~4001 après pull
CrystalEmojis::Cache.populated?  # => false puis true

# Vérification préalable avant de traiter un document — si le
# cache n'est pas encore peuplé, décider de la marche à suivre
# (avertir l'utilisateur, déclencher .pull, ou retomber
# gracieusement sur du texte).
unless CrystalEmojis::Cache.populated?
  puts "Lancez `emojis pull` pour la couverture complète."
end
----

== CLI

[source,shell]
----
# Compiler le binaire une fois.
shards build --release emojis

# Peupler le cache utilisateur avec le catalogue Twemoji complet.
emojis pull
# Téléchargement vers : /Users/.../Library/Caches/emojis/svg
# Source              : https://raw.githubusercontent.com/jdecked/twemoji/main/assets/svg
# Patientez (≈ 4000 SVG, ~18 Mo)...
# Téléchargé : 4001 nouveau(x) SVG (cache total : 4001)

# Utiliser un miroir privé.
emojis pull --source https://votre.miroir/twemoji/svg

# Cache système (configurations multi-utilisateurs).
emojis pull --system

# Inspection.
emojis info
# Emplacement : /Users/.../Library/Caches/emojis/svg
# Taille      : 4001 SVG
# Embarqués   : 208 (curated set)

# Vider le cache.
emojis purge
----

=== Exigences pour un miroir privé

La commande `pull` auto-découvre la liste des codepoints
disponibles de deux façons :

. **`MANIFEST.txt` à `<source>/MANIFEST.txt`** — un codepoint par
  ligne, hex minuscule, séquences multi-codepoint jointes par `-`.
  Commentaires (`#`) et lignes vides ignorés. **C'est l'interface
  recommandée pour un miroir privé.**
. **Fallback API GitHub** — fonctionne pour le repo Twemoji amont
  uniquement.

Donc un miroir privé doit juste héberger des fichiers `<key>.svg`
plus un `MANIFEST.txt` qui les liste. Un serveur statique nginx
de 2 lignes suffit.

=== Emplacement du cache

[cols="1,3"]
|===
| OS / mode | Chemin par défaut

| macOS (utilisateur)
| `~/Library/Caches/emojis/svg/`

| Linux/FreeBSD (utilisateur)
| `$XDG_CACHE_HOME/emojis/svg/` (défaut `~/.cache/emojis/svg/`)

| Tout (système via `--system`)
| `/var/cache/emojis/svg/`

| Tout (surcharge)
| variable d'env `$CRYSTAL_EMOJIS_CACHE_DIR`
|===
